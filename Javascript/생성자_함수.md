1. 생성자 함수가 필요한 이유
- 객체를 하나씩 만드는 방식은 객체 리터럴
- 회원, 상품처럼 비슷한 객체를 여러 개 만들어야 할 때 생성자 함수 사용

2. 기본 사용법
- 함수 이름 첫 글자는 대문자로
- 인자(이름, 나이)를 받아서 this에 넣음
- new 연산자로 호출, 값만 다르게 넘기면 비슷한 객체가 순식간에 여러 개 생성됨
- 붕어빵 틀, 와플 팬 같은 것. 재료(이름, 나이)를 넣고 찍어내는 방식

예시
function User(name, age) {
  this.name = name;
  this.age = age;
}
const user1 = new User('Mike', 30);

3. new를 붙이면 일어나는 일
- 빈 객체를 만들어 this에 할당
- 함수 본문을 실행하면서 this에 프로퍼티 추가
- 마지막에 this 반환
- 이 과정은 코드에 안 써도 new를 붙이는 순간 자동으로 동작
- 객체 리터럴로 일일이 쓰는 것보다 훨씬 빠르고 일관성 있게 만들 수 있음

4. 생성자 함수라고 특별한 건 없음
- 어떤 함수든 new를 붙이면 같은 과정이 동작
- 그래서 생성자 함수는 첫 글자를 대문자로 쓰는 게 관례

5. 메소드 추가
- this.sayName = function() { console.log(this.name); } 처럼 메소드도 넣을 수 있음
- user.sayName() 호출 시 this는 점 앞의 객체(user)
- 그래서 this.name은 user의 name

6. 실습: Item 생성자 함수
- 상품 이름(title), 가격(price) 받고, 가격을 보여주는 showPrice 메소드 추가
- new를 빼먹으면 그냥 일반 함수로 실행됨
- 함수가 아무것도 반환하지 않기 때문에 결과는 undefined
- 생성자 함수는 꼭 new를 붙여서 호출

결론: 비슷한 객체 여러 개 만들 때 유용, 객체 개념을 잘 잡아야 이후 프로토타입, 상속, 클래스 학습 가능
