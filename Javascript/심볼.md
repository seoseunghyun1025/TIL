# [JS 중급 #4] 심볼(Symbol)

## 심볼이 뭐야?
**세상에 딱 하나뿐인 값**이다. 이름표가 같아도 서로 다른 값으로 취급한다.

```js
const a = Symbol('id');
const b = Symbol('id');
a === b; // false (이름표만 같고 서로 다름)
```

## 어디에 써?
객체에 **몰래 속성을 추가**할 때 쓴다.
- 일반 키로 추가하면 `for...in`이나 `Object.keys()`로 객체를 돌 때 같이 튀어나온다.
- 심볼 키는 이런 반복문에서 **보이지 않는다.** 그래서 다른 사람이 만든 코드를 망가뜨리지 않는다.

```js
const id = Symbol('id');
const user = { name: 'Mike', [id]: 123 };

Object.keys(user); // ['name'] → id는 안 보임
user[id];          // 123 → 직접 꺼내면 보임
```

## 이름이 같으면 같은 값을 쓰고 싶을 때: Symbol.for()
```js
Symbol.for('id') === Symbol.for('id'); // true
```

## 한 줄 정리
- `Symbol()`: 만들 때마다 새로운 값이 나온다.
- `Symbol.for()`: 이름이 같으면 같은 값이 나온다.
- 심볼 키는 반복문에서 숨겨지지만 완전히 비밀은 아니다. `Object.getOwnPropertySymbols()`로 볼 수 있다.
