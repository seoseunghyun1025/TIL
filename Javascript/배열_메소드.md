# TIL: 배열 메소드 1 (Array methods)

> 출처: 코딩앙마 - 자바스크립트 중급 강좌 #7

## 1. `splice(n, m, x)`: 요소 지우기, 바꾸기, 끼워 넣기
- n번째부터 m개를 지운다. x 자리에 값을 넣으면 지운 자리에 그 값을 추가한다.
- m에 `0`을 넣으면 아무것도 안 지우고 **중간에 요소를 끼워 넣을 수 있다.**
- 원본 배열을 바꾸고, **삭제된 요소들을 배열로 반환**한다.

```js
let arr = [1, 2, 3, 4, 5];
arr.splice(1, 2);           // arr: [1, 4, 5]

let arr2 = [1, 2, 3, 4, 5];
arr2.splice(1, 3, 100, 200); // arr2: [1, 100, 200, 5]

let arr3 = ['나는', '철수', '입니다'];
arr3.splice(1, 0, '대한민국', '소방관');
// ['나는', '대한민국', '소방관', '철수', '입니다']

let arr4 = [1, 2, 3, 4, 5];
let result = arr4.splice(1, 2);
result; // [2, 3]  삭제된 요소
```

## 2. `slice(n, m)`: 일부 반환
- n부터 m **직전**까지 반환한다. m을 생략하면 끝까지다. 문자열의 `slice`와 같다.
- 괄호 안을 비우면 **배열이 복사**된다.

```js
let arr = [1, 2, 3, 4, 5];
arr.slice(1, 4); // [2, 3, 4]
arr.slice();     // [1, 2, 3, 4, 5] (복사본)
```

## 3. `concat()`: 합쳐서 새 배열 반환
- 배열이나 값을 각각 넘겨도 결과는 똑같다.

```js
let arr = [1, 2];
arr.concat([3, 4]);         // [1, 2, 3, 4]
arr.concat([3, 4], [5, 6]); // [1, 2, 3, 4, 5, 6]
arr.concat([3, 4], 5, 6);   // [1, 2, 3, 4, 5, 6]
```

## 4. `forEach(fn)`: 배열 반복
- 함수를 인수로 받는다. 함수의 매개변수는 (요소, 인덱스, 배열 자체) 순서이고, 보통 앞의 두 개만 쓴다.

```js
let users = ['Mike', 'Tom', 'Jane'];
users.forEach((name, index) => {
  console.log(`${index + 1}. ${name}`);
});
// 1. Mike  2. Tom  3. Jane
```

## 5. `indexOf` / `lastIndexOf` / `includes`
- `indexOf`: 찾으면 인덱스, 없으면 `-1`을 반환한다. 두 번째 인수는 **탐색을 시작할 위치**다.
- `lastIndexOf`: 끝에서부터 찾는다.
- `includes`: 인덱스는 필요 없고 포함 여부만 알고 싶을 때 쓴다. `true` 또는 `false`를 반환한다.

```js
let arr = [1, 2, 3, 4, 5, 1, 2, 3];
arr.indexOf(3);     // 2
arr.indexOf(3, 3);  // 7  (인덱스 3부터 탐색)
arr.lastIndexOf(3); // 7

arr.includes(2);    // true
arr.includes(8);    // false
```

## 6. `find(fn)` / `findIndex(fn)`
- `indexOf`처럼 찾는 건 같지만, **함수를 넘겨서** 짝수 찾기나 성인 찾기 같은 복잡한 조건을 쓸 수 있다.
- ⚠️ **첫 번째 true 값만** 반환하고 끝난다.
- 못 찾으면 `find`는 `undefined`, `findIndex`는 `-1`을 반환한다.
- 객체가 든 배열은 `indexOf`로 찾기 어려우니 이걸 쓰면 된다.

```js
let arr = [1, 2, 3, 4, 5];
arr.find((item) => item % 2 === 0); // 2 (첫 번째 짝수)

let userList = [
  { name: 'Mike', age: 30 },
  { name: 'Jane', age: 27 },
  { name: 'Tom', age: 10 },
];

userList.find((user) => user.age < 19);      // { name: 'Tom', age: 10 }
userList.findIndex((user) => user.age < 19); // 2
```

## 7. `filter(fn)`: 조건에 맞는 모든 요소
- 사용법은 `find`와 같고, 조건을 만족하는 **모든 요소를 배열로** 반환한다.

```js
arr.filter((item) => item % 2 === 0); // [2, 4]
```

## 8. `reverse()`: 역순 정렬
- 최근 가입한 유저부터 보여주거나, 게시판에서 최신 글 순으로 정렬할 때 자주 쓴다.

```js
[1, 2, 3, 4, 5].reverse(); // [5, 4, 3, 2, 1]
```

## 9. `map(fn)`: 가공해서 새 배열 반환 ⭐
- 함수로 각 요소를 가공한 결과를 **새로운 배열**로 반환한다. **원본 배열은 바뀌지 않는다.**
- 실무에서 정말 많이 쓰니 꼭 연습하자.

```js
let newUserList = userList.map((user, index) => {
  return Object.assign({}, user, {
    id: index + 1,
    isAdult: user.age > 19,
  });
});
// [{ name: 'Mike', age: 30, id: 1, isAdult: true }, ...]
// Tom은 isAdult: false
// userList는 그대로
```

## 10. `join()` / `split()`
- `join(구분자)`: 배열을 합쳐 문자열로 만든다. 인수를 안 넣으면 쉼표(`,`)로 합친다.
- `split(구분자)`: 문자열을 나눠 배열로 만든다. 빈 문자열(`''`)을 넣으면 한 글자씩 나눈다.

```js
let arr = ['안녕', '나는', '철수야'];
arr.join();    // '안녕,나는,철수야'
arr.join(' '); // '안녕 나는 철수야'
arr.join('-'); // '안녕-나는-철수야'

let users = 'Mike,Jane,Tom,Tony';
users.split(',');  // ['Mike', 'Jane', 'Tom', 'Tony']
'Hello'.split(''); // ['H', 'e', 'l', 'l', 'o']
```

## 11. `Array.isArray()`: 배열인지 확인
- 배열도 객체라서 `typeof`로는 일반 객체와 구분할 수 없다.

```js
let user = { name: 'Mike', age: 30 };
let userList = ['Mike', 'Tom', 'Jane'];

typeof user;     // 'object'
typeof userList; // 'object'

Array.isArray(user);     // false
Array.isArray(userList); // true
```

## 정리
- 원본을 바꾸는 메소드(`splice`, `reverse`)와 새 배열을 돌려주는 메소드(`slice`, `concat`, `filter`, `map`)를 구분하자.
- `find`와 `findIndex`는 첫 번째 하나만, `filter`는 조건에 맞는 전부를 찾는다.

# TIL: 배열 메소드 2 (sort, reduce)

> 출처: 코딩앙마 - 자바스크립트 중급 강좌 #8

## 1. `sort()`: 배열 재정렬
- ⚠️ **원본 배열 자체를 바꾼다.**
- 숫자나 영문자가 섞인 배열을 순서대로 정렬해준다.

```js
let arr = [1, 5, 4, 2, 3];
arr.sort(); // [1, 2, 3, 4, 5]

let arr2 = ['a', 'c', 'd', 'e', 'b'];
arr2.sort(); // ['a', 'b', 'c', 'd', 'e']
```

### 함정: 숫자 정렬
- 요소를 **문자열로 취급해서** 정렬한다. 그래서 1과 2로 시작하는 13, 27이 앞으로 온다.

```js
let arr = [27, 8, 5, 13];
arr.sort(); // [13, 27, 5, 8] 😱
```

### 해결: 비교 함수 넘기기
- `sort`는 함수를 인수로 받는다. 두 요소 a, b를 받아서 결과가 양수인지, 0인지, 음수인지만 알려주면 된다.

| 반환값 | 의미 |
|---|---|
| 음수 (a < b) | a를 앞으로 |
| 0 | 그대로 |
| 양수 (a > b) | b를 앞으로 |

```js
arr.sort((a, b) => a - b); // [5, 8, 13, 27]
```

### Lodash 쓰기
- 비교 함수를 직접 만들기보다는 유용한 함수를 모아둔 **Lodash** 같은 라이브러리를 많이 쓴다.
- `_.sortBy(arr)`를 쓰면 숫자, 문자, 객체 등 원하는 기준으로 정렬해준다. 실무에서 아주 자주 쓰니 공식 사이트에서 공부해보자.

## 2. `reduce(fn, 초기값)`: 누적 계산
- 배열을 돌면서 원하는 작업을 하고 **최종값을 반환**한다.
- 함수의 인자는 (누적 계산값, 현재값)이다. 첫 번째 인자는 이전 인덱스가 아니라 **지금까지 누적된 계산값**이다.
- 초기값은 생략할 수 있다. 생략하면 배열의 첫 번째 요소가 초기값이 된다.

```js
let arr = [1, 2, 3, 4, 5];

// forEach로 합 구하기
let result = 0;
arr.forEach((num) => {
  result += num;
});
// 15

// reduce로 한 번에
const result2 = arr.reduce((prev, cur) => {
  return prev + cur;
}, 0);
// 15  (0+1 → 1+2 → 3+3 → 6+4 → 10+5)

// 초기값을 100으로 하면 115
```

## 3. reduce 실전 예제
- `map`이나 `filter` 대신 `reduce`로 **배열을 반환**할 수도 있다.

```js
let userList = [
  { name: 'Mike', age: 30 },
  { name: 'Tom', age: 10 },
  { name: 'Jane', age: 27 },
  // ...
];

// 성인 이름만 뽑기 (초기값은 빈 배열)
let adults = userList.reduce((prev, cur) => {
  if (cur.age > 19) {
    prev.push(cur.name);
  }
  return prev; // 19세 이하면 지금까지 만든 배열을 그대로 반환
}, []);

// 나이 합계 (초기값 0)
let totalAge = userList.reduce((prev, cur) => {
  return (prev += cur.age);
}, 0);

// 이름이 세 글자인 사람만
let threeLetters = userList.reduce((prev, cur) => {
  if (cur.name.length === 3) {
    prev.push(cur.name);
  }
  return prev;
}, []);
```

## 4. `reduceRight()`
- `reduce`와 기능은 같지만 **배열의 오른쪽(끝)부터** 계산한다.

## 정리
- `sort()`로 숫자를 정렬할 땐 꼭 `(a, b) => a - b`를 넘기자.
- 상황에 맞게 `filter`, `map`, `forEach`, `reduce` 중 무엇을 쓸지 고르는 것도 실력이다.
