# TIL: 구조 분해 할당 (Destructuring assignment)

배열이나 객체의 속성을 **분해해서 그 값을 변수에 담는** 문법이다.

## 1. 배열 구조 분해
- 순서대로 변수에 할당된다.

```js
let [x, y] = [1, 2];
// x: 1, y: 2

let users = ['Mike', 'Tom', 'Jane'];
let [user1, user2, user3] = users;
// 아래 코드와 같음
// let user1 = users[0];
// let user2 = users[1];
// let user3 = users[2];
```

- `split()`이 반환하는 배열을 바로 분해할 수도 있다.

```js
let str = 'Mike-Tom-Jane';
let [user1, user2, user3] = str.split('-');
```

### 기본값
- 해당하는 값이 없으면 `undefined`가 들어간다. 기본값을 주면 이걸 막을 수 있다.

```js
let [a, b, c] = [1, 2];
// c: undefined

let [a = 3, b = 4, c = 5] = [1, 2];
// a: 1, b: 2, c: 5 (기본값 사용)
```

### 일부 값 무시
- 공백과 쉼표로 필요 없는 요소를 건너뛸 수 있다.

```js
let [user1, , user2] = ['Mike', 'Tom', 'Jane', 'Tony'];
// user1: 'Mike', user2: 'Jane'  ('Tom'과 'Tony'는 무시됨)
```

### 바꿔치기 (swap)
- 예전에는 임시 변수가 필요했다.

```js
// 예전 방식
let c = a;
a = b;
b = c;

// 구조 분해 할당 ✅ 임시 변수가 필요 없음
[a, b] = [b, a];
```

## 2. 객체 구조 분해
- 중괄호 `{}`로 감싸서 선언한다.
- 배열과 달리 **순서를 신경 쓰지 않아도 된다.** 프로퍼티 이름으로 매칭된다.

```js
let user = { name: 'Mike', age: 30 };

let { name, age } = user;
// 아래 코드와 같음
// let name = user.name;
// let age = user.age;

let { age, name } = user; // 순서를 바꿔도 동일하게 동작
```

### 새로운 변수 이름으로 할당
```js
let { name: userName, age: userAge } = user;
// userName: 'Mike', userAge: 30
```

### 기본값
```js
let { name, age, gender = 'male' } = user;
// user에 gender가 없으면 'male'

let user2 = { name: 'Jane', age: 18, gender: 'female' };
let { gender = 'male' } = user2;
// gender: 'female' (객체에 값이 있으면 그 값을 사용)
```

## 정리
- 배열은 **순서**로, 객체는 **프로퍼티 이름**으로 분해한다.
- 기본값, 일부 무시, 이름 바꾸기, swap을 기억하자.
