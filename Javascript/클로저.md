# TIL: 클로저 (Closure)

선행 학습: 중급 #1 (변수, 호이스팅, TDZ), 기초 #11 (함수 선언문과 함수 표현식)

## 1. 어휘적 환경 (Lexical Environment)
자바스크립트는 어휘적 환경을 갖는다. 코드가 위에서 아래로 실행되면서 이 환경이 어떻게 바뀌는지 따라가 보자.

```js
let one;
one = 1;

function addOne(num) {
  console.log(one + num);
}

addOne(5); // 6
```

| 시점 | 전역 Lexical 환경 |
|---|---|
| 코드 실행 직후 | `one`: 초기화 안 됨 (사용 불가, TDZ) / `addOne`: function (바로 사용 가능) |
| `let one;` | `one`: `undefined` (이제 사용해도 에러 없음) |
| `one = 1;` | `one`: `1` |
| `addOne(5)` 실행 | 함수용 **새 Lexical 환경**이 만들어짐 |

- `let`, `const`로 선언한 변수도 호이스팅된다. 환경에 올라가지만 초기화가 안 되어서 쓸 수 없을 뿐이다.
- **함수 선언문**은 바로 초기화된다. 그래서 선언보다 위에서도 쓸 수 있다.
- **함수 표현식**(변수에 함수를 할당하는 방식)은 변수와 똑같이 취급돼서 그렇게 할 수 없다.

## 2. 변수를 찾는 순서
- 함수가 호출되면 **내부 Lexical 환경**이 새로 만들어진다. 여기에는 매개변수와 지역 변수가 저장된다.
- 내부 Lexical 환경은 **외부 Lexical 환경에 대한 참조**를 갖는다.
- 변수를 찾을 때는 **내부 → 외부 → 전역** 순서로 범위를 넓혀 간다.

```js
// addOne(5) 안에서
// num → 내부 환경에서 찾음 ✅
// one → 내부에 없음 → 외부(전역)에서 찾음 ✅
```

## 3. 예제: makeAdder
```js
function makeAdder(x) {
  return function (y) {
    return x + y;
  };
}

const add3 = makeAdder(3);
console.log(add3(2)); // 5
```

1. 처음에는 `makeAdder`와 `add3`가 전역 환경에 올라간다. `add3`는 아직 초기화 전이다.
2. `makeAdder(3)`이 실행되면 새 환경이 생기고 `x: 3`이 저장된다.
3. `add3`에는 `makeAdder`가 반환한 함수가 들어간다.
4. `add3(2)`를 실행하면 또 새 환경이 생기고 `y: 2`가 저장된다.
5. `x + y`를 계산할 때 `y`는 내부에 있다. `x`는 내부에 없으니 **참조하는 외부 환경(`makeAdder`의 환경)** 에서 찾는다.

👉 `add3`는 자신의 `y`를 가지고 있고, 상위 함수인 `makeAdder`의 매개변수 `x`에도 접근할 수 있다. `makeAdder` 실행이 끝난 뒤에도 마찬가지다.

## 4. 클로저란?
> **함수와 그 함수의 렉시컬 환경의 조합**

- 함수가 생성될 당시의 외부 변수를 **기억**한다.
- 생성된 이후에도 그 변수에 **계속 접근**할 수 있다.
- 외부 함수의 실행이 끝나서 외부 함수가 사라진 뒤에도, 내부 함수는 외부 함수의 변수에 접근할 수 있다.

### 각자 다른 환경을 가진다
```js
const add3 = makeAdder(3);
const add10 = makeAdder(10);

add10(5); // 15
add3(1);  // 4 (add10을 만들어도 add3에는 아무 영향 없음)
```

## 5. 예제: 카운터와 은닉화
```js
function makeCounter() {
  let num = 0; // 외부 함수의 변수

  return function () {
    return num++;
  };
}

let counter = makeCounter();

console.log(counter()); // 0
console.log(counter()); // 1
console.log(counter()); // 2
```

- 내부 함수가 외부 함수의 변수 `num`에 접근하고, 생성된 뒤에도 그 값을 계속 기억한다.
- **바깥에서 `num`을 직접 바꿀 방법이 없다.** 갑자기 99로 바꾸거나 2씩 올리는 건 불가능하다.
- 오직 `counter()`를 호출해서 1씩 늘리는 것만 가능하다. 이것을 **은닉화**라고 한다.

## 정리
| 개념 | 설명 |
|---|---|
| Lexical 환경 | 변수와 함수가 저장되는 공간. 함수가 호출될 때마다 새로 만들어진다 |
| 변수 탐색 | 내부 → 외부 → 전역 순서로 찾는다 |
| 클로저 | 함수 + 그 함수가 생성될 때의 렉시컬 환경 |
| 핵심 | 외부 함수가 끝나도 내부 함수는 외부 변수를 기억하고 접근할 수 있다 |
| 활용 | 같은 함수로 독립된 환경 여러 개 만들기 (`add3`, `add10`), 외부에서 수정 못 하게 숨기기 (은닉화) |
