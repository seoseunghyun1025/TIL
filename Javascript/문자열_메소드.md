# TIL: 문자열 메소드 (String methods)

## 1. 따옴표와 백틱
- 작은따옴표(`'`)와 큰따옴표(`"`)는 크게 다르지 않으니 상황에 맞게 쓰면 된다.
  - HTML처럼 안에 큰따옴표가 있으면 작은따옴표로 감싸는 게 편하다.
  - 영어 문장처럼 안에 작은따옴표(`'`)가 있으면 큰따옴표로 감싼다.
- 백틱(`` ` ``)은 `${}`로 변수나 표현식을 넣을 수 있고, **여러 줄을 그대로 쓸 수 있다.**

```js
let html = '<div class="box">hi</div>';
let desc = "It's 3 o'clock.";

let name = 'Mike';
let result = `My name is ${name}.`;

let multi = `안녕
하세요`;           // OK
let single = '안녕\n하세요'; // 작은따옴표는 \n을 써야 하고, 한 줄로만 써야 함
```

## 2. length / 특정 위치 접근
- `length`로 문자열 길이를 알 수 있다. 회원가입 시 아이디나 비밀번호 길이를 제한할 때 쓴다.
- 배열처럼 `[인덱스]`로 특정 위치의 문자에 접근한다. 인덱스는 0부터 시작한다.
- ⚠️ 배열과 달리 **한 글자만 바꾸는 건 안 된다.** 에러는 없지만 아무 변화가 없다.

```js
let desc = '안녕하세요.';
desc.length; // 6
desc[2];     // '하'
desc[4] = '용';
desc;        // '안녕하세요.' (그대로)
```

## 3. 대소문자 변환
```js
let desc = 'Hi guys. Nice to meet you.';
desc.toUpperCase(); // 'HI GUYS. NICE TO MEET YOU.'
desc.toLowerCase(); // 'hi guys. nice to meet you.'
```

## 4. `indexOf(text)`
- 문자를 받아 몇 번째에 있는지 반환한다. 0부터 세고, 없으면 `-1`을 반환한다.
- 여러 개 포함돼 있어도 **첫 번째 위치만** 반환한다.
- ⚠️ `if`문에 그대로 쓰면 위험하다. 맨 앞에 있으면 `0`이 반환되는데, `0`은 false로 취급된다.

```js
desc.indexOf('to');  // 14
desc.indexOf('man'); // -1

if (desc.indexOf('Hi')) {
  console.log('Hi가 포함됨'); // 출력 안 됨 (결과가 0이라서)
}

if (desc.indexOf('Hi') > -1) {
  console.log('Hi가 포함됨'); // ✅ 항상 -1보다 큰지 비교
}
```

## 5. 문자열 자르기

| 메소드 | 동작 |
|---|---|
| `slice(n, m)` | n부터 m **직전**까지 반환. m을 생략하면 끝까지, 음수면 끝에서부터 센다 |
| `substring(n, m)` | n과 m **사이**를 반환. n과 m을 바꿔도 동작한다. 음수는 0으로 인식한다 |
| `substr(n, m)` | n부터 시작해서 **m개**를 가져온다 |

```js
let desc = 'abcdefg';

desc.slice(2);      // 'cdefg'
desc.slice(0, 5);   // 'abcde'
desc.slice(2, -2);  // 'cde'

desc.substring(2, 5); // 'cde'
desc.substring(5, 2); // 'cde'

desc.substr(2, 4);  // 'cdef'
desc.substr(-4, 2); // 'de'
```

## 6. `trim()` / `repeat(n)`
- `trim()`: 앞뒤 공백을 제거한다. 사용자 입력을 받을 때 주로 쓴다.
- `repeat(n)`: 문자열을 n번 반복한다.

```js
'   coding   '.trim(); // 'coding'
'hello!'.repeat(3);    // 'hello!hello!hello!'
```

## 7. 문자열 비교
- 문자열도 크기 비교가 된다. 기준은 아스키 코드다(`'A'`는 65, `'B'`는 66, `'a'`는 97).
- 숫자를 외울 필요는 없다. **a보다 z가 크고, 대문자보다 소문자가 크다**는 것만 기억하자.

```js
'a' < 'c';                  // true
'a'.codePointAt(0);         // 97
String.fromCodePoint(97);   // 'a'
```

## 8. 실전 예제
**목차에서 앞의 숫자 빼고 글자만 뽑기**

```js
let list = [
  '01. 들어가며',
  '02. JS의 역사',
  '03. 자료형',
];

let newList = [];
for (let i = 0; i < list.length; i++) {
  newList.push(list[i].slice(4)); // 인덱스 0~3은 필요 없음
}
// ['들어가며', 'JS의 역사', '자료형']
```

**금칙어 '콜라' 체크하기**

```js
// ❌ 틀린 예: 없으면 -1(true), 맨 앞이면 0(false)
function hasCola(str) {
  if (str.indexOf('콜라')) {
    console.log('금칙어가 있습니다.');
  } else {
    console.log('통과');
  }
}

// ✅ indexOf는 -1보다 큰지 비교
function hasCola(str) {
  if (str.indexOf('콜라') > -1) {
    console.log('금칙어가 있습니다.');
  } else {
    console.log('통과');
  }
}

// ✅ includes: 있으면 true, 없으면 false
// 위치가 필요 없고 있는지 없는지만 볼 때 좋다
function hasCola(str) {
  if (str.includes('콜라')) {
    console.log('금칙어가 있습니다.');
  } else {
    console.log('통과');
  }
}
```

## 정리
- `indexOf`의 결과를 `if`에 그대로 넣지 말고 `> -1`로 비교하자. 있는지만 확인할 거면 `includes`가 더 간단하다.
- `slice`는 m 직전까지, `substring`은 n과 m 사이, `substr`은 m개다.
