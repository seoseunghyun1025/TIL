코딩앙마 자바스크립트 중급 강좌 #1 요약: 변수, 호이스팅, TDZ

1. var와 let/const의 기본 차이
- let, const는 ES6부터 도입, 그 전엔 var만 사용
- var는 다시 선언해도 에러 없음
- let은 에러 발생, 다시 선언하면 에러

2. 호이스팅
- var는 선언 전에 사용해도 에러 없음
- 선언이 스코프 최상단으로 끌어올려진 것처럼 동작 이를 호이스팅
- 이때 값은 undefined
- 선언만 올라가고 할당은 원래 자리에 남기 때문

3. TDZ(Temporal Dead Zone)
- let, const도 호이스팅 됨
- 단, TDZ 영역에 있는 동안 사용 불가, ReferenceError 발생
- 호이스팅은 스코프 단위
- 함수 안에서 같은 이름의 let 변수를 나중에 선언하면, 그 함수 안에선 바깥 변수도 못 쓰고 에러남

4. 변수 생성 3단계: 선언 → 초기화 → 할당
- var: 선언 + 초기화 동시 진행, 할당 전에 쓰면 undefined
- let: 선언과 초기화 분리, 실제 코드 줄에 도달해야 초기화, 그 전에 쓰면 ReferenceError
- const: 선언 + 초기화 + 할당 한 번에 해야 함, 선언만 하고 나중에 할당하면 에러남

5. 스코프
- var는 함수 스코프, let/const는 블록 스코프
- 블록 = 함수, if문, for문, while문, try/catch문
- if문 안에서 var로 선언한 변수는 if문 밖에서도 사용 가능
- let, const는 블록 안에서만 사용 가능
- var도 함수 밖으로는 못 벗어남

결론: var 대신 let, const 사용 권장, 결과 예측 쉽고 버그 줄일 수 있음
