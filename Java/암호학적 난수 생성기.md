### 암호학적 난수 생성기

#### 1. 사용 이유
- 일반 Random 함수는 난수를 생성하기 위해 **의사 난수**를 생성
  - **의사 난수**란?: 난수처럼 보이게 하기 위해 어떠한 알고리즘을 사용한 규칙적인 난수를 생성하는 것
- **Random**이란?
  - Random을 생성하기 위해선 시드라는 씨앗이라고 불리는 기준이 되는 값을 세팅
  ```java
  Random random = new Random(); //seed = System.nanoTime();
  ```
  - 값을 넣지 않으면 시스템 시간을 통해 시드가 정해짐
  - 규칙적으로 값이 만들어짐
  - **시드값이 동일**하다면 매번 같은 값을 보여줌

#### 2. SecureRandom이란
- **OS**에서 임의 데이터를 가져와서 시드로 사용
- SHA1을 사용하여 의사 난수를 생성하는 **SHA-1** 해시를 계산한 다음 작업에서 1씩 증가하는 64비트 카운터와 연결
