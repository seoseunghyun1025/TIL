## 방어적 복사
- 내부의 객체를 반환할 때 객체의 복사본을 만들어서 반환하는 것
- 복사한 외부의 객체를 번경해도 원본 내부 객체가 변경되지 않음

### 얕은 복사, 깊은 복사
- **얕은 복사**: 
  - 원본 객체를 복사할 때 원본 객체의 주소 값을 참조하는 복사
  - 원본이나 복사한 객체가 변경되면 서로 영향을 미침
- **깊은 복사**: 
  - 원본 객체를 복사할 때 새로운 객체를 만들고 원본 객체의 모든 값을 복사 -> 원본 객체로부터 독립적인 객체 생성
  - 원본과 복사한 객체가 독립적으로 변경이 되어도 서로 영향을 미치지 않음

### 방어적 복사를 쓰는 이유
- 깊은 복사를 쓰면 매번 재귀적으로 모두 새로 생성하여 메모리 낭비

### 방법
```java
import java.util.ArrayList;
import java.util.List;

class Mart {
    private final List<String> products;

    // 생성자에서 방어적 복사
    public Mart(List<String> externalList) {
        this.products = new ArrayList<>(externalList); 
    }

    // 방어적 복사로 실행된 객체 접근
    public void addProduct(String product) {
        this.products.add(product);
    }

    public void printSize() {
        System.out.println("마트 상품 개수: " + this.products.size());
    }
}

public class Main {
    public static void main(String[] args) {
        List<String> externalList = new ArrayList<>();
        externalList.add("마우스");

        Mart myMart = new Mart(externalList);

        // 외부에서 리스트에 노트북을 슬쩍 추가해 봄
        externalList.add("노트북");

        // 방어적 복사 덕분에 1이 출력
        myMart.printSize(); // 출력: 마트 상품 개수: 1
        
        // 정식으로 추가하려면 마트의 메서드를 사용해야 함
        myMart.addProduct("노트북");
        myMart.printSize(); // 출력: 마트 상품 개수: 2
    }
}
```
### 사용하는 곳
- **결제/주문 시스템**
  - 금액이나 상품 목록이 절대 임의로 변경되면 안됨
  - 예: 주문이 완료된 이후에 사용자가 외부에서 기존 장바구니 리스트에 비싼 음식을 추가했을 때 이미 생성된 주문 내역서의 결제 금액이나 상품 목록까지 같이 바뀜
- 날짜를 표현하는 Period나 User 정보를 담는 객체처럼 데이터가 변하지 않아야 하는 불변 객체를 만들 때
- **정보 조회 API**
  - Getter 메서드를 만들 때 내부 원본 리스트가 오염되는 것을 막기 위해 사용
