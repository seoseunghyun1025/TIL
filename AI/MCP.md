MCP 영상 상세 요약 (조코딩)
MCP의 개념, 이미 만들어진 MCP를 연결하는 법, 직접 만드는 법, 더 쉽게 공유하는 법까지 다루는 영상이에요. 18:55 이후는 광고(Ale AI) 파트예요.

1. MCP가 왜 필요한가 
LLM만으로는 한계가 있어요. LLM은 다음 단어를 예측해서 그럴싸한 말을 만드는 모델일 뿐이에요. 그래서 "오늘 날씨 알려줘"라고 물으면 "12도, 맑음"처럼 지어낸 답(할루시네이션)을 해요.
도구를 연결하면 달라져요. 기상청과 연결된 날씨 도구가 있으면 AI가 도구를 호출해 실제 데이터를 받고, 그걸 바탕으로 답해요. 

API로도 연결할 수는 있어요. Gmail, 캘린더, Slack에는 다 API가 있어요. 하지만 API마다 AI가 쓰기 쉽게 따로 맞춰서 개발해야 해서 번거로웠어요. 

그래서 표준이 생겼어요. 2024년 11월에 Anthropic(Claude 개발사)이 Model Context Protocol을 발표했고, 많은 기업이 쓰면서 사실상 표준이 됐어요. 

USB-C 비유: 도구가 MCP 규격에 맞춰 만들어져 있으면, 꽂기만 해도 MCP 클라이언트의 AI가 바로 쓸 수 있어요. 

프로토콜은 그냥 형식이에요. 편지 봉투에 보내는 사람은 왼쪽 위, 받는 사람은 오른쪽 아래, 우표는 어디에 붙이는지 정해진 틀이 있는 것과 같아요. 

2. 활용 사례: Blender MCP 

Blender는 3D 애니메이션이나 게임 제작에 쓰는 3D 편집 도구예요.
사용법을 몰라도 Claude Desktop에 Blender MCP를 연결하고 이미지를 첨부해 "이렇게 3D로 만들어 줘"라고 하면, AI가 MCP로 Blender를 직접 조작해서 3D 오브젝트를 만들어요.
Figma, Notion, 캘린더 같은 도구도 같은 방식으로 AI가 직접 다룰 수 있어요. 

3. 기존 MCP 연결하기: Claude Desktop + Context7 

MCP 클라이언트 (MCP를 연결할 수 있는 프로그램): Claude 데스크톱 앱(웹 버전 X), Cursor, VS Code 등

Claude 데스크톱 앱(Windows/macOS)을 설치해요. 

왼쪽 아래 메뉴 → 설정 → 개발자 탭으로 가면 MCP 서버 연결 화면이 나와요. 영상에서는 이 앱에서 로컬 MCP 서버만 연결할 수 있다고 설명해요. 

Smithery에서 MCP를 찾아요. MCP를 모아 두고 쉽게 연결하게 해 주는 사이트로, 영상 시점에 6,341개가 있었어요. 

Context7을 골라요. Next.js 같은 라이브러리의 최신 개발 문서를 가져와서 AI가 참고하게 해 주는 MCP로, 개발자들이 많이 써요. 

연결 방식에서 JSON → Windows용 설정을 복사해요. 

Claude에서 구성 편집을 누르면 claude_desktop_config.json 파일이 열려요. 비어 있는 MCP 서버 항목에 복사한 내용을 붙여 넣어요. 이 설정은 cmd로 Smithery를 통해 Context7을 실행하라는 명령어예요. 

저장(Ctrl+S)하고 Claude를 완전히 종료한 뒤 다시 켜면 Context7이 동작해요. 내 컴퓨터에서 실행되는 로컬 서버예요. 

사용 예: "Next.js로 새 웹사이트를 만들고 싶은데 Context7 MCP로 새 앱 만드는 명령어를 찾아와 줘" → 도구 사용 허용 알림 → 공식 Next.js 문서를 바탕으로 답해요. 

4. MCP 직접 만들기: FastMCP (Python) 
FastMCP는 MCP 개발용 라이브러리예요. 언어별로 있고, 영상에서는 Python을 썼어요.
서버를 만들고 함수에 @mcp.tool 어노테이션만 붙이면 MCP 표준에 맞는 도구가 돼요. API 만들듯이 만들면 돼요.
도구(tool) 말고도 리소스(자료 불러오기), 프롬프트 템플릿도 설정할 수 있어요. 가장 많이 쓰는 건 도구예요. 

예제는 두 수 a, b를 더해 반환하는 덧셈 함수예요. 이 자리에 회사 DB나 날씨 API를 연결하는 함수를 넣으면 그게 곧 사내 MCP, 날씨 MCP가 돼요. 
python



Copy
# 영상 설명을 바탕으로 재구성한 형태 (화면 코드와 다를 수 있음)
from fastmcp import FastMCP

mcp = FastMCP("add")

@mcp.tool
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b
서버를 실행하면 localhost:8000/mcp에서 켜져요.

설정 → MCP 서버에서 쉽게 연결할 수 있어요. 영상에서는 유저 DB MCP와 사내 규정이 담긴 Notion MCP를 연결했어요. 
데모 1: "외근할 때 식비는 얼마까지 쓸 수 있어?" → Notion 검색 도구로 실제 사내 규정을 가져와 답해요. 일반 ChatGPT라면 지어낸 답을 했을 질문이에요. 
데모 2: "지난 일주일간 가입자 수 알려줘" → 유저 DB 도구로 실제 데이터를 조회해요.

Slack 연동: 업무 채널에 봇을 초대하고 태그해서 "지난 한 달간 신규 가입자 수 알려줘"처럼 물어보면 MCP 도구를 호출해 답해요.
