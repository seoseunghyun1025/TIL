## @Component
- 이 클래스는 스프링이 관리해 줘라고 등록하는 어노테이션
- "나를 스프링 빈으로 등록해 주세요"라고 선언하는 마크

### 동작
- 스프링부트 프로젝트를 만들면 기본적으로 들어있는 @SpringBootApplication 어노테이션 안에 컴포넌트 스캔 기능이 포함
- 스프링이 실행될 때 지정된 패키지 하위를 싹 훑음
- 클래스 위에 @Component가 붙어있는 것을 발견하면 해당 클래스의 인스턴스를 1개만 생성해 스프링 컨테이너에 등록
- 이렇게 등록된 빈은 나중에 다른 곳에서 **생성자 주입**을 통해 가져다 쓸 수 있게 됨

### @Service, @Controller 모두 @Component
- **@Controller / @RestController**: "이 클래스는 웹 요청을 받고 응답하는 컨트롤러야!"
- **@Service**: "이 클래스는 비즈니스 로직을 처리하는 서비스야!"
- **@Repository**: "이 클래스는 데이터베이스와 통신하는 데이터 접근 계층이야!"

> **의존성 주입**: 개발자는 선언만 스프링이 알아서 객체 만들고 따로 보관하고 적재적소에서 사용해줌
