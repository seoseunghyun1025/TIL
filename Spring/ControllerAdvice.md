### ControllerAdvice
#### 1. 정의
- 전역 예외 처리나 공통 데이터 바인딩, 모델 속성 등을 관리하기 위해 사용하는 컴포넌트
- 컨트롤러들을 밖에서 보조해주는 역할을 하는 클래스
- 모든 페이지에서 공통으로 쓰이는 네비게이션 데이터나 공통 모델 속성을 주입하기 위해 사용

#### 2. 주요 역할
- 프로젝트 내의 모든 뷰에서 공통으로 사용해야 하는 데이터를 **미리 담아둘 때** 사용
- 전역 예외 처리 `@ExceptionHandler`
  - 개별 컨트롤러마다 try-catch나 예외 처리를 반복해서 작성할 필요 없이 프로젝트 전원에서 발생하는 특정 예외(`NullPointException`, 공통 `Exception` 등)를 한곳에서 모아 공통 에러 페이지나 JSON 응답으로 처리가능

#### 3. 브레드크럼브와 무슨 연관?
- 페이지 경로를 화면 상단에 계층 구조로 보여줌
  - 매번 페이지를 이동할 때마다 뷰로 넘겨주면 중복이 발생 그래서 @ControllerAdvice 클래스 내에 선언 후 현재 요청된 URL 주소나 메뉴 ID를 분석해 목록을 자동으로 생성한 후 모든 모델에 담아주는 방식으로 구현

#### 4. ControllerAdvice(annotations = Controller.class)
- 일반 `@Controller`가 붙은 클래스들에만 한정하겠다는 뜻
- `@RestController`는 제외하고 `@Controller`만 한정
- `@ResponseBody`가 붙은 클래스는?
  - 클래스 자체가 `@Controller`이기 때문에 어드바이스의 적용을 받음
  - 하지만 `@ResponseBody` 메소드는 화면을 안 거치고 데이터를 바로 응답하기 때문에 모델에 담긴 브레드크럼브 같은 데이터는 무시되거나 넘어가게 됨
