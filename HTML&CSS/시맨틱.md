## HTML Ep05 - 시맨틱(Semantic) 태그

### 시맨틱 태그란?
- 의미가 있는 태그
- 과거에는 영역을 나눌 때 의미가 없는 <div>나 <span> 태그에 class="header" 같은 이름을 붙여서 역할을 구분
- 예: `<h1>`은 "페이지 제목"이라는 뜻을 가짐
- `<span>`을 CSS로 `h1`처럼 보이게 만들 수는 있지만, 의미가 전달되지 않으니 쓰지 말기

### 쓰면 좋은 점
- 검색 엔진 최적화(SEO): 네이버·구글 검색 결과 상위에 뜰 가능성 ↑
- 웹 접근성: 스크린 리더가 의미를 알아듣고 강조해 줌
- 가독성: `<div class="header">`보다 `<header>`가 훨씬 읽기 쉬움

### 레이아웃 태그
- `<header>`: 페이지 상단, 페이지 정보
- `<nav>`: 메뉴(내비게이션)
- `<main>`: 실제 본문 영역
- `<footer>`: 하단, 저작권 같은 사이트 정보
- `<section>`: 페이지 안에서 영역을 나눌 때
- `<article>`: 여러 태그를 묶어서 반복해 쓰는 단위 (예: 쇼핑몰 상품 목록의 상품 하나)

> - 예전엔 `<div class="header">`처럼 div + class로 레이아웃을 만들었음
> - 화면 결과는 같아도 HTML5 시맨틱 태그를 쓰는 게 맞음
