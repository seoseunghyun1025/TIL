## HTML Ep04_3 - 표(Table) 태그

### 기본 태그
- `<table>`: 표 전체를 감쌈
- `<caption>`: 표 제목/설명
- `<tr>`: 행(row)
- `<th>`: 제목 칸 (기본으로 굵게 + 가운데 정렬)
- `<td>`: 일반 데이터 칸

> - `th`, `td`는 반드시 `tr` 안에 있어야 함
> - `tr` 안에는 `th`나 `td`가 꼭 있어야 함

### 그룹 태그
- `<thead>`: 제목 행 묶기
- `<tbody>`: 일반 데이터 행 묶기
- `<tfoot>`: 표 하단 영역(평균, 합계 등) 묶기
- `<colgroup>` + `<col>`: 열을 묶음. `col`은 열 개수만큼 넣고, 열 너비·배경색을 한 번에 바꿀 수 있음

### 셀 병합
- `colspan="2"`: 열(가로) 병합
- `rowspan="2"`: 행(세로) 병합
- 병합한 만큼 남는 칸(`td`)은 지워야 함

> `rowspan`은 그룹(`tbody`, `tfoot`)을 넘어서 병합되지 않음

### 웹 표준 주의
- 대부분의 table 속성(`border`, `width` 등)은 웹 표준이 아님 → 모양은 CSS로 넣기
- 테두리가 두 겹으로 보이면 `table`에 `border-collapse: collapse;`
- `colspan`, `rowspan`이 가장 많이 쓰는 속성
