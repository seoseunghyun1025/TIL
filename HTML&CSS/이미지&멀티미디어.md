## HTML Ep07_1 - 이미지 태그 & 경로

### `<img>` 속성
- `src` (필수): 이미지 경로
- `alt` (권장): 이미지를 설명하는 텍스트
  - 스크린 리더가 읽어줌 → 웹 접근성 ↑
  - 네트워크 오류 등으로 이미지를 못 불러오면 화면에 대신 표시됨
- `width` / `height`: 너비·높이 (픽셀 단위, 숫자만 쓰면 됨. 예: `width="200"`)

### 상대 경로 (현재 파일 위치 기준)
- 같은 폴더: `img.jpg` 또는 `./img.jpg`
- 상위 폴더: `../img.jpg`
- 두 단계 위: `../../img.jpg`
- 하위 폴더: `images/img.jpg`

### 절대 경로
- `http`로 시작하는 전체 주소
- `/`로 시작: 현재 도메인이 앞에 자동으로 붙음 → 루트 디렉터리부터 찾음
  - 예: `/images/wolf.jpg` → 프로젝트 최상위에 `images` 폴더가 있어야 함
- PC에서는 `C:\...`처럼 드라이브부터 시작

> 루트 디렉터리 = 최상위 폴더 (Windows는 C 드라이브). 웹 문서 기준으로는 프로젝트의 최상위 폴더
> 이미지가 안 뜨면 개발자 도구 → Network 탭에서 실제로 어떤 경로를 요청했는지 확인

## HTML Ep07_2 - 멀티미디어 & 링크 태그 (audio, video, a)

### `<audio>`: 웹 문서에 오디오 넣기
- 쓰는 방법은 두 가지
  - `<audio src="경로">`: img처럼 src에 경로를 바로 넣는 방식
  - `<audio>` 안에 `<source>` 넣기: 파일을 여러 개 지정할 수 있고, 브라우저가 그중 가장 적합한 파일을 고름
- `controls`가 없으면 화면에 아무것도 안 보임

### `<video>`: 웹 문서에 비디오 넣기
- 사용법은 audio와 같음 (src, type 등)

### audio/video 공통 속성
- `controls`: 재생 컨트롤 바 표시
- `autoplay`: 자동 재생. Chrome, Firefox에서는 `muted`를 함께 써야 동작함
- `loop`: 반복 재생
- `muted`: 음소거
- `preload`: 페이지가 로드될 때 파일을 어떻게 불러올지 지정
- `width` / `height`: 크기 지정
- `poster` (video 전용): 재생 전에 보여줄 썸네일 이미지

> 속성은 외울 필요 없음. 필요할 때 MDN에서 찾아보기

### `<a>`: 하이퍼링크
- `href`로 다른 페이지, 같은 페이지의 특정 위치, 파일, 이메일 등에 연결
- `<a>` 안에 텍스트를 넣으면 텍스트 링크, `<img>`를 넣으면 이미지 링크
- `target="_blank"`: 새 탭에서 열기 (가장 많이 씀)
- 같은 페이지 안에서 이동: 목적지 요소에 `id="target"`을 주고 `href="#target"`으로 연결
- 메일 보내기: `href="mailto:이메일주소"`

### 실습 팁
- 루트에 `assets/` 폴더를 만들고 이미지, 오디오, 비디오 파일을 정리함. 파일을 옮긴 뒤에는 경로도 함께 수정해야 함
