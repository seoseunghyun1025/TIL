## HTML Ep09 - Head 태그

### `<head>`: 문서 정보(메타데이터)를 담는 태그
- 브라우저 화면(body)에는 보이지 않는 **문서 자체의 정보**를 정의함
- 예: 브라우저 탭의 아이콘(파비콘), 탭 제목, 카카오톡이나 SNS에 링크를 보냈을 때 뜨는 제목·설명·이미지
- HTML 기본 구조: `<html>` 안에 `<head>`(문서 정보)와 `<body>`(화면에 보이는 내용)

### head 안에 들어가는 요소
- `<title>`: 브라우저 탭에 표시되는 제목
- `<link>`: 외부 리소스와 연결 (파비콘, 외부 CSS 파일 등)
- `<style>`: CSS 스타일 규칙 작성. 실무에서는 보통 `<link>`로 외부 CSS 파일을 연결함
- `<base>`: 문서 안 모든 **상대 경로의 기준 URL**을 바꿈
- `<meta>`: 다른 태그로 표현할 수 없는 기타 정보 (SNS 미리보기 등)
- `<script>`: 웹 문서에 JavaScript 코드를 넣을 때 사용

### 파비콘 넣기 실습
- 파비콘 생성 사이트에서 이미지를 업로드하고 crop한 뒤 `.ico` 파일로 다운로드
- HTML 파일과 같은 폴더에 넣고 `<title>` 위에 link 태그로 연결

```html
<link rel="icon" href="./favicon.ico">
```

### `<base>` 실습
- base를 넣으면 상대 경로의 기준이 **현재 문서 위치에서 base에 지정한 경로로** 바뀜
- 예: base를 `/assets/images/`로 지정하면 `./favicon.ico`는 `assets/images/` 폴더에서 찾음
- 그래서 base를 넣자 파비콘이 사라졌고, 파일을 images 폴더로 옮기니 다시 보임

### Open Graph(OG) 메타 태그
- SNS(카카오톡, 네이버 블로그, 페이스북, 트위터 등)에 링크를 공유할 때 보여줄 요약 정보(제목, 설명, 이미지, URL)를 설정함
- 트위터, iOS·Android 앱용 태그는 따로 나뉨

> head 태그는 웹사이트의 문서 정보를 담는 곳이라는 정도만 이해하면 됨. 각 태그를 지금 다 몰라도 사이트를 만드는 데 문제없고, 필요할 때 하나씩 익히면 됨
