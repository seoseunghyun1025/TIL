## HTML Ep04_2 - 목록(List) 태그

- `<ol>`: 순서 있는 목록 (예: 계란 프라이 만드는 순서) → 앞에 번호가 붙음
- `<ul>`: 순서 없는 목록 (예: 3대 운동 벤치·데드·스쿼트) → 앞에 점(•)이 붙음
- `<li>`: 목록 항목. 반드시 `ul` / `ol` 안에 넣어야 함
- `<dl>`: 정의 목록 ("A는 B다" 같은 사전식)
  - `<dt>`: 정의할 용어(제목)
  - `<dd>`: 그 용어에 대한 설명

> - `li`, `dt`, `dd`는 혼자 쓸 수 없음 (`li`는 `ul`/`ol` 안에, `dt`/`dd`는 `dl` 안에)
> - `ul` 바로 아래에는 `li`만 넣어야 함
> - `dl`에는 `dt`+`dd`가 최소 한 쌍 있어야 하지만, 꼭 1:1일 필요는 없음 (`dt` 2개 + `dd` 1개도 가능)
> - 실무에서는 `ul`을 가장 많이 씀

### 꿀팁
- Emmet: `li*3` + Tab → `li` 3개 생성 / `dl>(dt+dd)*3` → `dt`+`dd` 3쌍 생성
- VS Code 멀티 선택: Windows `Ctrl + Alt + ↓` / Mac `Cmd + Option + ↓`

```html
<dl>
   <dt>정의 제목1</dt>
   <dt>정의 제목2</dt>
   <dt>정의 제목3</dt>
   <dd>정의 설명</dd>
</dl>

<dl>
   <dt>정의 제목1</dt>
   <dt>정의 제목2</dt>
   <dt>정의 제목3</dt>
   <dd>정의 설명1</dd>
   <dd>정의 설명2</dd>
   <dd>정의 설명3</dd>
</dl>

<dl>
   <dt>정의 제목</dt>
   <dd>정의 설명1</dd>
   <dd>정의 설명2</dd>
   <dd>정의 설명3</dd>
</dl>
```
