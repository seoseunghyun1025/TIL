## HTML Ep04_1 - 폰트(Font) 태그

### 기본 텍스트 태그
- `<h1>` ~ `<h6>`: 제목/소제목. 숫자가 작을수록 큰 제목
- `<p>`: 문단(paragraph)
- `<hr>`: 가로 구분선. 닫는 태그 없음
- `<br>`: 줄바꿈. 내용이 없어서 닫는 태그 없음

### 기울임 / 굵게
- `<i>`: 기울임 (단순 스타일)
- `<em>`: 기울임 + 강조(emphasis)
- `<b>`: 굵게 (단순 스타일)
- `<strong>`: 굵게 + 중요한 내용 강조

### b·i vs strong·em
- 화면에서는 똑같이 보이지만 쓰는 목적이 다름
- `b`, `i` → 그냥 모양만 바꿀 때
- `strong`, `em` → 의미상 중요한 부분을 강조할 때
- 스크린 리더(시각장애인에게 화면 내용을 읽어주는 프로그램)는 `strong`, `em`을 더 강한 억양으로 읽어줌 → **웹 접근성** 향상
- 결론: 중요한 내용에는 `strong` / `em`을 쓰자
